## Getting Started

Firstly, open your terminal in the folder where you want the site and type:

```
git clone https://github.com/lbniko/fun.git
```

Then,

```
cd fun
```


## Trying it out

Run

```
npm run dev
```

then visit `localhost:3000` to view the website.
